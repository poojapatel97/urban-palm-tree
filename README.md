# urban-palm-tree

Dragon and avatars game implementation.

## Run

```bash
python dragon_and_avatars_game.py
```

Input format:

1. `dragon_health dragon_attack`
2. `number_of_avatars`
3. `avatar_health avatar_attack` (repeated for each avatar)

Output:

- `DRAGON` if the dragon defeats all avatars
- `AVATARS` otherwise
